TITLE: Morse Key — dot, dash, wait, repeat
PROMPT: Give the visitor a real telegraph desk: a bakelite key you can actually feel, 70 ms of thumb deciding dot from dash, and a receiver side that sends typed words back out in beeps and amber light.
DESCRIPTION: Two panels on one warm wooden desk. TRANSMITTER: a big round key (mouse, touch or SPACE) whose press length splits dots from dashes; the current element string updates live, a 450 ms silence closes a letter through a reverse code table, 1.1 s opens a word space, and a 640 Hz side-tone with LED keeps honest company. RECEIVER: type any message (PARIS CALLS LONDON preloaded), watch its code print above, and SEND replays it as scheduled oscillator tones with the LED flashing in sync.
TECHNIQUES: press-duration timing thresholds for dit/dah, layered setTimeout state for letter/word gaps, reverse dictionary decoding, WebAudio oscillator scheduling on the audio clock for playback, gain envelope click cleanup, LED sync via offset timers, responsive twin-pane desk.
INTERACTION: Mash the key (or SPACE) like you mean it — short for dot, long for dash — let the pauses spell for you, then type anything in the receiver and SEND THE MESSAGE to hear your words clatter across the wire.
