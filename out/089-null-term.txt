TITLE: Null Term — terminal for things that do not exist
PROMPT: An amber CRT with scanlines and a sardonic shell: a fake prompt where every invented command punishes curiosity with a joke, history works, and sudo has feelings about your choices.
DESCRIPTION: A bezelled tube — radial phosphor glow, animated scanline overlay, blinking block cursor, scrolling output with a text-shadow bloom — running NULL-TERM v0.0.1. The input line lives at the bottom of the screen and echoes into a persistent scrollback: help lists twelve impossible verbs, and ls, cat, date, uptime, fortune, ping, tree, rm, echo and sudo each answer with precisely engineered regret (ping reports 100% packet loss to the void; tree ends in one regret). Arrow keys walk history, Enter runs, and the easter eggs (vim, exit, sudo make me a sandwich) fire like confetti inside the joke.
TECHNIQUES: single-input keypress shell loop with backspace/edit history, output element factory with auto-scroll, setTimeout-staggered fake command replies (async/await sleep), CRT simulation via repeating-gradient scanlines and flicker keyframes, phosphor glow via text-shadow.
INTERACTION: TYPE — try help, fortune, ping, sudo, vim, exit; ↑↓ to replay your mistakes; the terminal never breaks character, and the cursor keeps blinking at you judgmentally.
